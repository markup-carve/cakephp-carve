# Installation

Require `markup-carve/cakephp-carve` in a CakePHP 5 application, then add `$this->addPlugin('MarkupCarve/CakeCarve');` in `Application::bootstrap()`.

Copy values from [the configuration example](https://github.com/markup-carve/cakephp-carve/blob/main/config/app.example.php) into your app configuration when you need to change defaults. The plugin reads settings under `Carve`.
